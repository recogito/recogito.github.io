## How Plugins Work

Recogito Studio plugins are packages that act as [Astro integrations](https://docs.astro.build/en/guides/integrations-guide/).

The sections below cover installing plugins and [enabling them](#enabling-an-installed-plugin) per project. To build your own plugin, see the [SDK Guide](/guides/sdk/).

## Installing plugins

### Development environments

1. `npm install` the plugin's npm package or GitHub repository to add it to the client's `package.json`.
2. List the same package name in the `INSTALLED_PLUGINS` environment variable in the client's `.env`.
3. Restart the dev server, or rebuild the client if you're running a build.

The package must be **both** installed **and** listed under the `INSTALLED_PLUGINS` environment variable. This compiles the plugin into your instance and makes it available to every project.

### Self-hosted environments

List the package name in the `INSTALLED_PLUGINS` environment variable. The package name can be an NPM package or a GitHub repository, and can optionally include a version tag (`mypackage@2.0`).

The `install` and [upgrade](/guides/self-hosting/#upgrading) scripts will install the package into the client application for you.

Some plugins depend on additional services — the [NER plugin](https://github.com/recogito/plugin-ner), for example, requires Trigger.dev and Stanford CoreNLP. See [Additional Services](/guides/self-hosting/#additional-services) in the self-hosting guide.

## Enabling an Installed Plugin

Plugins are enabled on a per-project basis, and are disabled by default.

To enable a plugin for a project:

1. Open a project as a **Project Admin**.
2. Go to **Project Settings → Plugins** and click **Browse Available Plugins**.
3. The gallery lists every plugin compiled into your instance. Select one to install it for this project.
4. If the plugin exposes settings, configure them from the same screen.
5. To disable a plugin for the project, remove it here.

If a plugin you installed doesn't appear in the gallery, it was installed incorrectly. Recheck that its package is listed in `INSTALLED_PLUGINS` (and, in a development environment, installed with `npm install`), then rebuild the client or restart the dev server.
