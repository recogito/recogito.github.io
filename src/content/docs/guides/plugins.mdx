## Installing Plugins

Recogito Studio plugins are packages that act as [Astro integrations](https://docs.astro.build/en/guides/integrations-guide/). They are compiled into the client when it is built, which makes them available to every project on the instance.

The client loads the plugins listed in the `INSTALLED_PLUGINS` environment variable, a comma- or space-separated list:

```bash
INSTALLED_PLUGINS="@recogito/plugin-geotagging,@recogito/plugin-revisions"
```

Each entry can be:

- an npm package name, optionally with a version: `@recogito/plugin-ner@1.2.0`
- a public GitHub repository: `owner/repo`, `github:owner/repo#ref`, or `https://github.com/owner/repo`
- a GitHub repository with an explicit package name: `my-plugin@github:owner/repo`

Plugins installed from a GitHub repository are built on install, so the repository needs a `prepare` script that builds the plugin (for example `"prepare": "npm run build"`).

### Development Environments

In the root of your `recogito-client` checkout:

1. Install the plugin:

   ```bash
   npm install @recogito/plugin-geotagging
   ```

2. Add the same entry to `INSTALLED_PLUGINS` in the client's `.env`.
3. Restart the dev server, or rebuild the client if you're running a build.

The package must be **both** installed **and** listed in `INSTALLED_PLUGINS`.

### Self-Hosted Environments

Add the entry to `INSTALLED_PLUGINS` in your `docker/.env`. The install script (`install-self-hosted-docker.sh`) and the [upgrade script](/guides/self-hosting/#upgrading) (`upgrade.sh`) install the packages into the client for you.

To add or remove a plugin on an instance that is already running, edit `INSTALLED_PLUGINS` and run `./upgrade.sh` to rebuild the client.

### Plugins With Extra Requirements

The [NER plugin](https://github.com/recogito/plugin-ner) additionally requires Stanford CoreNLP and another Trigger.dev project separate from the one used for import/export. See [Additional Services](/guides/self-hosting/#additional-services) in the self-hosting guide and the plugin's README.

## Enabling an Installed Plugin

Plugins are enabled on a per-project basis, and are disabled by default.

To enable a plugin for a project:

1. Open a project as a **Project Admin**.
2. Go to **Project Settings → Plugins** and click **Browse Available Plugins**.
3. The gallery lists every plugin compiled into your instance. Select one to install it for this project.
4. If the plugin exposes settings, configure them from the same screen.
5. To disable a plugin for the project, remove it here.

If a plugin you installed doesn't appear in the gallery, it was installed incorrectly. Recheck that its package is listed in `INSTALLED_PLUGINS` (and, in a development environment, installed with `npm install`), then rebuild the client or restart the dev server.
